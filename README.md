# Da EA a cBot

Esplorazione tecnica: come mappare un Expert Advisor MQL5 in un cBot cTrader, struttura a constructor/regole e prove di campo.

## Contenuti
- `README.md` — panoramica del progetto.
- `docs/schema.md` — schema di mapping EA → cBot.
- `prove/` — codice e appunti delle prove.

## Obiettivo
Definire un flusso riproducibile per convertire logiche di trading da MT5 a cTrader senza riscrivere l’intero codice da zero.
